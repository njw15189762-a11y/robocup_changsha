- 没有可见目标时前往按机器人编号分配的内圈搜索航点；追踪使用带速度阻尼的控制器，并叠加近距离队友斥力。

## 2026-09-23：E003 目标历史与速度估计

- 目标离开视野后最多外推 4 步，并按目标场地边界进行反射修正；记忆过期后恢复原搜索行为。
- 提交预检通过；8 个公开回合全部 `status=ok`，`performance_score=183.3333`，碰撞率仍为 0。
- 各场景结果与 E002 完全相同，因此本次改动在公开套件上没有可测得的分数增益。

## 2026-09-23：E004 删除竞价失败 fallback

- 在 E003 基础上只删除一个行为：机器人输掉目标竞价后，不再继续追逐最近的可见目标，而是进入原有搜索流程。
- 提交预检通过；8 个公开回合全部 `status=ok`，`performance_score=183.3333`，全部逐回合指标与 E003 相同。
- `coop-0` 中分配已从 `[0, 0, None]` 变为 `[None, 0, None]`，说明修改确实生效。
- 分数不变的原因是机器人 1 追逐目标 0 的轨迹没有变化，最后最近距离仍为 0.179，未达到 0.15 的覆盖半径；机器人 0 和 2 的搜索也未在十步内发现目标 1、2。
- 结论：取消重复追逐使分工语义更清楚，但单独使用不能解决 `coop-0`，下一瓶颈是搜索路径或目标 0 的接近速度。
