# P007 训练策略计划

## 当前判断

当前规则策略的本地公开分为 225.0000。连续调整搜索半径、搜索网格、固定方向、
初始位置航点和航点整体角度，都没有稳定减少 crossing 零覆盖场景。规则搜索已经
进入低信息增益阶段，下一阶段转向学习策略。

模板训练脚本目前只读取公开套件的 `basic-0`，因此实际只在 `uniform` 布局训练；
它没有系统看到 `crossing`。此外，官方团队奖励只有目标进入 0.15 覆盖半径后才为正，
对从零开始的 PPO 来说过于稀疏。

## T001：均衡场景和势函数奖励

第一项训练实验只建立独立候选，不替换当前规则策略。

1. 训练回合按 1:1 交替使用 `uniform` 和 `crossing`，训练种子与公开集、现有开发集隔离。
2. 保留官方奖励，并在训练阶段加入目标到最近机器人距离的势函数差分奖励：
   `r_shape = alpha * (gamma * phi(s_next) - phi(s))`。
3. 势函数使用所有目标到最近机器人的截断距离，只用于训练；评测和提交推理仍只使用
   协议提供的局部观测。
4. 前期使用较强的 `alpha` 帮助探索，中期降低，最后阶段令 `alpha=0`，只用官方奖励微调。
5. 使用共享策略网络，第一版保持两层 MLP，便于继续导出为审计允许的 NumPy 权重。

## 数据划分

- 训练种子：新建独立连续区间，不使用 1001–2002、31001–32020。
- 模型选择集：另建固定的 uniform/crossing 均衡小套件。
- 最终验证：现有 40 回合开发集只用于阶段性复核，不根据单个场景反复调参。
- 公开8回合只作最终复核，不用于选择 checkpoint。

## 训练顺序

1. 先运行 20k–50k 步冒烟训练，验证环境轮换、奖励分解、学习曲线和模型导出。
2. 冒烟正常后运行约 500k–1M 步正式训练，每 50k 步保存 checkpoint。
3. 按独立模型选择集成绩挑选 checkpoint，而不是直接采用训练结束模型。
4. 导出后执行 SB3 与 NumPy 动作一致性检查。
5. 只有候选同时超过开发集 163.3333 和公开集 225.0000，才考虑替换当前规则策略。

## 风险控制

- 按当前本地约定，训练和评测统一使用 `enter`；该环境已经安装
  `requirements-train.lock`，修改依赖后必须同时复查 `pip check` 和提交预检。
- 奖励塑形只能存在于训练包装器中，不能修改官方 `coverage_bench`。
- 所有训练实现、配置和记录限制在 `participant/P007/`，模型与大体积中间文件放在
  `outputs/P007/`。
- 如果端到端 PPO 无法超过规则策略，下一方案是保留规则追踪，仅学习无目标可见时的
  搜索动作，而不是继续扩大端到端网络。
